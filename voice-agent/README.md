# Zaki Assistant — Voice Agent

Zaki's personal voice assistant, built on ElevenLabs Agents.

- **Talk to it:** https://elevenlabs.io/app/talk-to?agent_id=agent_0901m7nt31bpejktby4gt34s5wpg
- **Agent ID:** agent_0901m7nt31bpejktby4gt34s5wpg
- **Languages:** English (default), Urdu, Pashto, German, switched automatically
- **Brain:** Claude Haiku 5.5 with a knowledge base

## What it knows
- German law, benefits and bureaucracy (general information, for everyone):
  `knowledge/02-german-law-guide.md`
- Zaki's personal profile (family only, after the family code). It lives only in
  ElevenLabs, not in this repository. The code is also kept only in ElevenLabs.
- Behaviour rules: `knowledge/03-agent-rules.md`

Do not store passwords, bank details or ID numbers in the profile.

## History
Every conversation is saved in ElevenLabs (Agents → Zaki Assistant → History), with no expiry.
